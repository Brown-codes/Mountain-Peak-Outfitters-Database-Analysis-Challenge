# Mountain Peak Outfitters Database Analysis Challenge

## Overview
This project involves analyzing sales data for Mountain Peak Outfitters, a national outdoor retailer with 25 stores across the country. You'll work with a PostgreSQL database to extract insights that will help management make strategic decisions about inventory, marketing, and staffing.

## Deliverables
* SQL scripts answering all 22 business questions listed below
* A brief summary report (1-2 paragraphs) for each question explaining your findings
